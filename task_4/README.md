Датасет: Titanic - Machine Learning from Disaster

Обучите модель на наборе данных Titanic для предсказания выживания пассажиров. Проведите анализ важности признаков и визуализируйте результаты.

Характеристика датасета
  Датасет содержит информацию о 891 пассажире Титаника. Целевая переменная — Survived (1 — выжил, 0 — погиб). Признаки: пол, возраст, класс билета, количество родственников на борту, стоимость билета, порт посадки. После обработки данных для обучения использовалось 7 признаков. Данные несбалансированы: выживших меньше, чем погибших.

Результаты моделей

  QDA показала наибольшую точность — 82.1%. Это означает, что модель правильно определила судьбу 147 из 179 пассажиров в тестовой выборке.

Бустинги
  XGBoost, Gradient Boosting, LightGBM и CatBoost показали близкие результаты: точность 80.4–81.6%. Все они работают на деревьях решений и исправляют ошибки последовательно.

Ансамбли бэггинга
  Extra Trees и Decision Tree показали точность 79.9%. Это ниже, чем у бустингов, но выше, чем у линейных методов.

Линейные модели
  Linear SVM показал точность 79.3%. QDA оказалась лучше (82.1%), вероятно, поскольку она учитывает нелинейные зависимости между признаками.

KNN
  Точность KNN составила 70.4% — худший результат среди всех моделей, кроме Dummy. Модель усредняет всех «близких» соседей,не учитывая, что что пол и возраст могут быть важнее, чем номер билета или порт посадки.

Базовый уровень (Dummy)
  Dummy предсказывал самый частый класс (0 — погиб) и показал точность 58.7%. Все модели превзошли этот результат, что подтверждает, что признаки несут полезную информацию.
